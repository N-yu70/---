# 食光智语 API（P1 · 零依赖版）

**无需 npm install**，只要有 Node.js 即可运行。

## 一键启动

双击 **`start.bat`**，或在终端执行：

```bash
cd server
node src/index.js
```

看到以下输出表示成功：

```
食光智语 API http://127.0.0.1:3000 （零依赖，无需 npm install）
健康检查: http://127.0.0.1:3000/api/health
```

浏览器打开 http://127.0.0.1:3000/api/health 应返回 JSON。

## 小程序联调

1. 保持后端运行（不要关闭终端窗口）
2. 微信开发者工具 → **详情 → 本地设置** → 勾选 **不校验合法域名**
3. 重新编译小程序

模拟器会自动请求 `http://127.0.0.1:3000/api`。

## 离线模式

若后端未启动，小程序会自动切换 **离线模式**，使用本机存储，不再报错阻塞。

启动后端后重新编译，即可恢复云端同步。

## 正式微信登录（可选）

复制 `.env.example` 为 `.env`，填写：

```
WX_APP_ID=你的AppID
WX_APP_SECRET=你的AppSecret
```
